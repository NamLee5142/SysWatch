# Decisions

One file per decision that would be expensive to reverse, written when it is
made rather than reconstructed afterwards. Numbered in the order they were
taken, and never renumbered.

A decision record is not a design document. It says what was chosen, what the
alternatives were, and why they lost - so that the next person to ask the
question can see whether anything has changed, instead of re-running the
argument from the start.

Superseded records stay. The history of a decision is part of it.
